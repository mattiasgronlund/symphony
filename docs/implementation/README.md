# Phased Implementation Documentation

This directory stores the execution layer derived from `SPEC.md`.

- `ROADMAP.md` — phase order, outcomes, dependencies, readiness, and status.
- `TRACEABILITY.md` — requirement-to-phase and requirement-to-evidence mapping.
- `templates/` — reusable templates for phase plans and supporting artefacts.
- `phases/` — one living ExecPlan per implementation phase.

Do not copy full requirement wording into every file. Reference stable requirement IDs and keep canonical wording in `SPEC.md`.
