# Roadmap Review Checklist

- Every normative SPEC requirement has a stable ID.
- Every ID appears in traceability.
- Every traceability phase exists in the roadmap.
- Every phase is a vertical outcome, not only a technical layer.
- Shared requirements name all applicable phases.
- Deferred, rejected, and blocked items have rationale.
- Discovery spikes have decision criteria.
- Dependencies are explicit.
- Documentation paths and links resolve.
- Existing repository instructions are preserved.
- No unrelated code changes are present.
